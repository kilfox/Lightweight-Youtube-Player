# LightYTP GUI Hotkeys

| Key | Action |
| --- | --- |
| `Ctrl+F` | Focus search |
| `Enter` | Search while the search box is focused |
| `Space` | Play or pause |
| `Left` / `Right` | Seek backward or forward five seconds |
| `Up` / `Down` | Raise or lower volume by 5% |
| `N` / `P` | Play the next or previous queued track, or navigate an active radio session |
| `S` | Stop playback |
| `Y` | Toggle autoplay radio on or off |
| `Ctrl+Q` | Quit and stop the background player |

Double-click any search result, queue entry, history entry, or favorite to play it.

On Windows and macOS, LightYTP GUI accepts hardware play/pause, play, pause, stop, next, and previous buttons from keyboards, headsets, and earbuds. The operating system decides which active media app receives them. Linux support depends on the desktop environment.
